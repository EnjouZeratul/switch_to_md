# Sample Test Files

This directory contains test samples for switch_to_md development.

## Documents

Place test files here:
- `sample.pdf` - PDF document
- `sample.docx` - Word document
- `sample.xlsx` - Excel spreadsheet
- `sample.pptx` - PowerPoint presentation
- `sample.txt` - Plain text
- `sample.html` - HTML document
- `sample.epub` - EPUB ebook

## Images

- `sample.png` - PNG image
- `sample.jpg` - JPEG image
- `sample.gif` - GIF image
- `chart.png` - Chart/diagram image (for visual-semantic testing)
- `formula.png` - Math formula image

## Audio

- `sample.mp3` - MP3 audio
- `sample.wav` - WAV audio
- `speech.mp3` - Speech audio (for transcription testing)
