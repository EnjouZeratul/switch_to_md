# Supported Formats

## 文档类（无需配置）

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| PDF | `.pdf` | 文本提取，扫描件需视觉插件 |
| Word | `.docx`, `.doc` | 完整格式保留 |
| Excel | `.xlsx`, `.xls` | 多 Sheet，表格输出 |
| PowerPoint | `.pptx`, `.ppt` | 每页提取 |
| 纯文本 | `.txt`, `.md`, `.rtf` | 直接输出 |
| HTML | `.html`, `.htm` | HTML → MD |
| EPUB | `.epub` | 电子书章节提取 |

## 图片类（需视觉插件）

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| PNG | `.png` | OCR + 语义分析 |
| JPEG | `.jpg`, `.jpeg` | OCR + 语义分析 |
| GIF | `.gif` | OCR + 语义分析 |
| BMP | `.bmp` | OCR + 语义分析 |
| TIFF | `.tiff`, `.tif` | OCR + 语义分析 |
| WebP | `.webp` | OCR + 语义分析 |

## 音频类（需音频插件）

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| MP3 | `.mp3` | 语音转写 + 时间戳 |
| WAV | `.wav` | 语音转写 + 时间戳 |
| FLAC | `.flac` | 语音转写 + 时间戳 |
| OGG | `.ogg` | 语音转写 + 时间戳 |
| M4A | `.m4a` | 语音转写 + 时间戳 |
| AAC | `.aac` | 语音转写 + 时间戳 |

## 代码/配置类（无需配置）

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| JSON | `.json` | 语法高亮 + 结构摘要 |
| YAML | `.yaml`, `.yml` | 语法高亮 |
| XML | `.xml` | 语法高亮 |
| CSV | `.csv` | 表格输出 |
| SQL | `.sql` | 语法高亮 |
| JavaScript | `.js` | 语法高亮 |
| TypeScript | `.ts` | 语法高亮 |
| Python | `.py` | 语法高亮 |
| 更多 | `.java`, `.go`, `.rs` 等 | 语法高亮 |

## 矢量类（无需配置）

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| SVG | `.svg` | 元信息 + 文本内容 + 源码 |
